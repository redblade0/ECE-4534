# Bundled vendor dependencies
This is the source and SysConfig metadata subset of TI MSPM0 SDK 2.11.00.07,
from the same SDK revision used for the course baseline. It supplies driver
libraries, device headers, startup/linker templates, and peripheral configuration
tools. It does not include the TI example applications or the instructor solution.
Retain the TI and third-party licenses when redistributing this directory.
This is a dependency subset, not a complete SDK installation or documentation set.
